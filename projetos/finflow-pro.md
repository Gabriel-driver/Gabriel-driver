# FinFlow Pro

Controle financeiro pessoal, com frontend em React e TypeScript e API em Node.js. Repositório público.

[github.com/Gabriel-driver/finflow-pro](https://github.com/Gabriel-driver/finflow-pro)

## O que faz

- Contas, receitas e despesas
- Categorias, cartões, metas e orçamento do mês
- Relatórios
- Login com sessão própria
- PostgreSQL
- Testes unitários e de ponta a ponta

Deploy previsto na Vercel, com segredo e banco só nas variáveis de ambiente.

## Para quem está contratando

O trabalho atual é uma operação de logística. O sistema saiu do zero e a equipe usa.

- Aplicativo interno em Next.js e TypeScript: operação, comercial, financeiro, indicadores e portal do colaborador
- CRM operacional no rastreio, com WhatsApp na Evolution, hospedada no servidor
- CRM comercial implementado, com a linha oficial na API Cloud da Meta
- Assistente de IA no rastreio e outro na cotação, em módulos separados
- Site público e área do cliente, com sessão no servidor
- Robôs em Python: SQL Server do ERP para o PostgreSQL de painel, comissão, prazo e tarifa
- Publicação por imagem no GitHub Actions. A VPS puxa a versão pronta
- Permissão por função para financeiro, visão de várias unidades e área do cliente
